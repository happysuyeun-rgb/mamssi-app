# 공감숲에 글이 안 보일 때 — 쉽게 확인하기

---

## 방법 1. Supabase에서 3단계로 확인 (클릭만)

1. **Supabase** 들어가기 → 왼쪽에서 **Table Editor** 클릭  
2. **community_posts** 테이블 선택  
3. 맨 아래쪽 **가장 최근 글** 하나 보기  
   - **내가 쓴 글이 여기 있나요?**  
     - **없어요** → 앱에서 공개 기록 저장할 때 **카테고리(일상/고민 등)** 를 꼭 선택했는지 확인해 보세요.  
     - **있어요** → 그 줄에서 **is_public** / **is_hidden** 칸을 보세요.  
       - **is_public** = 체크(✓) 또는 true  
       - **is_hidden** = 비어 있거나 false  
       - 이렇게 되어 있으면 공감숲에 나와야 합니다. 반대면 나오지 않습니다.

---

## 방법 2. 한 번에 확인 (SQL 한 번 실행)

Supabase 왼쪽 메뉴에서 **SQL Editor** 클릭 → **New query** 선택 후 아래 전체를 복사해서 붙여넣기 → **Run** 클릭.

```sql
-- 공감숲에 실제로 보이는 글 개수
SELECT COUNT(*) AS "공감숲에_보이는_글_개수"
FROM community_posts
WHERE is_public = true AND (is_hidden = false OR is_hidden IS NULL);

-- 최근 공개 감정 기록 중 공감숲에 안 올라간 것 (원인 확인용)
SELECT e.id, e.content, e.is_public, e.category, e.created_at,
       CASE WHEN cp.id IS NULL THEN '❌ 공감숲에 없음' ELSE '✅ 공감숲에 있음' END AS 상태
FROM emotions e
LEFT JOIN community_posts cp ON cp.emotion_id = e.id
WHERE e.is_public = true
ORDER BY e.created_at DESC
LIMIT 10;
```

- **첫 번째 결과**: "공감숲에_보이는_글_개수" — 지금 공감숲에 나오는 글 수  
- **두 번째 결과**: 최근 공개 기록 10개가 **공감숲에 있음/없음** 표시  
  - **❌ 공감숲에 없음** → 그 글은 공감숲에 안 보이는 글입니다.  
  - **✅ 공감숲에 있음** → 그 글은 공감숲에 올라가 있는 글입니다.

## 방법 3. 한 번에 고치기 (트리거 수정 + 지난 공개 기록까지 넣기)

**이미지처럼 "공개 + 카테고리 있는데 전부 공감숲에 없음"이면** 트리거가 안 돌아가고 있을 가능성이 큽니다.

1. Supabase 왼쪽 메뉴 → **SQL Editor** → **New query**
2. 프로젝트 안의 **`supabase_fix_and_backfill_forest.sql`** 파일 내용 **전체 복사**해서 붙여넣기
3. **Run** 클릭

이 스크립트는 두 가지를 합니다.

- **트리거 수정**: `emotions`에는 없는 `emotion_type` 대신 `main_emotion`만 쓰도록 고칩니다. (에러 나던 트리거가 정상 동작하게 됨)
- **백필**: 이미 저장된 공개 기록(공개 + 카테고리 있는 것)을 **한 번에** `community_posts`에 넣어서 공감숲에 보이게 합니다.

실행 후 앱에서 공감숲을 새로고침해 보세요.

---

## 한 줄 요약

- **공개 기록** 저장할 때 **카테고리(일상/고민/연애 등)** 를 꼭 하나 선택하면 공감숲에 올라갑니다.  
- **전부 공감숲에 없음**이면 **방법 3**으로 `supabase_fix_and_backfill_forest.sql` 한 번 실행해 보세요.
